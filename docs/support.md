# Nodal Analytics Plugin Support

Nodal Analytics is an open-source plugin maintained by Nodal Data.

## Get help

- Read the [quickstart](https://docs.nodaldata.io/quickstart) and the local
  [getting-started guide](getting-started.md).
- Report reproducible bugs or request enhancements through
  [GitHub Issues](https://github.com/nodal-data/nodal-context/issues).
- Send general questions to [info@nodaldata.io](mailto:info@nodaldata.io).

Include the plugin version, agent host and version, operating system, relevant
error message, and minimal reproduction steps. Do not include credentials,
private warehouse data, customer data, or other secrets.

## Security issues

Do not post suspected vulnerabilities in a public issue. Follow the
[security policy](../SECURITY.md) to use GitHub private vulnerability reporting
or contact [security@nodaldata.io](mailto:security@nodaldata.io).

Open-source support is provided on a reasonable-effort basis. Separate hosted
Nodal products have their own support arrangements.
